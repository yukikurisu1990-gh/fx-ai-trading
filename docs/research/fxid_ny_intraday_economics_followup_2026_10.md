1. **情報と注文 flow の到来の集中**: 開場で新しい情報と顧客の注文が集まり、order flow には持続的な価格の影響がある（Evans & Lyons 2002、JPE）。ただし order flow の価格の影響は、主に**同時点**で起きる。過去の価格の変化から将来の変化を予測できることは意味しない。
2. **大口の注文の分割執行**: 実需や運用会社の大口の注文を、時間をかけて執行する。分割執行が観測できない場合に限り、価格は数時間かけて動く。
3. **日中の momentum の文献**:
   - 米国株（SPY）で、取引の最初の 30 分の return が最後の 30 分の return を予測する（Gao, Han, Li, Zhou 2018、JFE）。
   - FX でも、RUB / USD などで類似の報告がある（Elaut, Frömmel, Lampaert 2018、J. Financial Markets）。
   - ただし、どちらも「開場の後 → 引けの前」の特定の区間で、開場の 1〜2 時間後から 4 時間の継続ではない。

**測られた事実との衝突**【実測（過去研究）】:

- seen data の M15〜数時間の VR < 1、IC 負（反転側の構造）。
- Round 1 で、M15 の決定の尺度に edge なし。
- session の gate を付けた trend・MTF の一致の戦略は、**gross の時点で負**（#500 §3）。
- **fix の flow**【公開資料・未照合】:
  - London 16:00 の WMR fix（通常 11:00 ET）の前に drift があり、後に反転する（Evans 2018、Krohn・Mueller・Whelan の fixing の研究）。
  - 09:00〜13:00 の保有はこの fix をまたぐので、fix の前の drift と後の反転の両方を含み、継続の仮説には不利に働く。
- 機構 1 と 2 が数時間の継続を作るなら、M15〜H1 の尺度で正の自己相関が観測されるはずだが、測られたのは逆だった。両立させるには「反転は短い lag だけで、開場の後だけ数時間の継続が別に存在する」という追加の構造が要る。それを支える独立の証拠は、手元に無い。

**評価**:

- **S1 の継続の符号を、測られた反転の構造に対して支える機構を、根拠を持って書けない。**
- #500 の終了条件 (iv) により、**S1 は外すことを推奨**する。
- **反転させれば利益が出るという推測で、逆方向の戦略に変えることはしない**（失敗した規則は反転した規則ではない）。

## 13. S2 の経済的機構（data を使わない）

**仮説**: 08:30 ET の米国の定時発表の 30 分後に、価格の反応の方向に入り、保有する（継続）。

**論点**:

| 論点 | 整理 |
| --- | --- |
| 30 分後以降の継続の機構【公開資料・未照合】 | 発表への FX の反応は、条件付き平均の調整（jump）が数分以内に大部分が終わり、vol だけが長く高い（Andersen, Bollerslev, Diebold, Vega 2003、AER。Ederington & Lee 1993、JF）。発表の後の order flow が価格の発見に寄与し続けるという報告はある（Evans & Lyons 2008、JFE。Love & Payne 2008、JFQA）が、**30 分を過ぎた後に、予測可能な drift が 4 時間続くことの証拠は弱い**。#500 も「文献では drift は 1 時間以内が多い」と記録している |
| 過去の CPI の研究との重複 | #472 / #473 は、CPI の surprise の符号を使い、検出力のある帰無の結果だった。S2 は surprise ではなく価格の反応を使うが、**反応の方向は surprise の符号と強く相関する**ので、独立の試行ではない |
| 発表の瞬間の spread | M15 の終値の snapshot では捕まえない。09:00 の entry（30 分後）の spread は通常並み（1.66 bp）に戻っているので、S2 の entry の cost の問題は小さい。重要な発表の日だけの spread は分けていない |
| 09:00 以降の採算性 | 基本条件では基準内（0.137）。**S2 の現実的な頻度**（主要な発表で、1 pair 年 24〜50 回【推測】）では、n = 50 で 0.161 となり超える。年 100 回に届かせるには、毎週木曜の失業保険の申請件数のような小さな発表まで含める必要があり、その反応は小さい【推測】 |

**評価**:

- **S2 の、30 分後から 4 時間の継続を支える経済的機構は弱い。**
- 頻度について【推測】の値（年 24〜50 回）を感度に入れると、経済性も基準を超える（n = 50 で 0.161、n ≈ 24 なら 0.080 + 1/√72 ≈ 0.198）。これは感度で、主判定ではない。
- S2 を無理に研究候補として残す必要はないと判断する。

## 16. 帰無モデルの再設計方針（設計の比較のみ。実 data の読み取りと max-T の本実行は無し）

Cycle 1 の帰無（bar ごと・全 pair 共通の ±1）は、pair 間の相関と vol の塊を保つが、**時系列の依存（M15 の自己相関、測られた VR < 1）を壊す**。

時計に錨を下ろした規則（S1 / S2 のような、決まった時刻に、それより前の情報で side を決める規則）の帰無は、「entry の前の情報は、entry の後の方向を予測しない」である。

| 案 | 操作 | 保つもの | 壊すもの | 評価【算術】 |
| --- | --- | --- | --- | --- |
| A. bar ごとの符号（Cycle 1） | M15 の bar ごとに共通の ±1 | 相関、|return|、vol の塊 | 自己相関、entry の前後の関係 | 系列依存がある市場の帰無の分布を正しく再現しない |
| B. 日ごとの block の符号 | 取引日ごとに、その日の全 bar に共通の ±1 | 日中の自己相関 | 日をまたぐ drift | **時計の規則には使えない**。side が同じ日の return の奇関数（例: 開場の後の動きの符号）なら、side と保有中の return が同時に反転し、規則の損益は**どの replication でも変わらない**。帰無の分布が退化する |
| C. **entry で分けた block の符号** | 日ごとに、entry より前の区間と、entry から exit の区間に、独立な ±1（全 pair 共通） | 保有中の区間の内部の依存（vol の経路・自己相関）、pair 間の相関、entry の前の区間の内部の依存 | entry の前と後の符号の関係（これがまさに検定したい情報） | **時計の規則の帰無として推奨**。entry の時刻が規則ごとに固定であることが前提 |
| D. 日の順序の並べ替え（block bootstrap） | 日を単位に再標本化 | 日中の構造全部 | 日をまたぐ依存 | 規則の損益を中心化しないと、帰無ではなく推定の分布になる。max-T の帰無には C の方が素直 |

- 案 C の注意: 保有中の区間の内部の自己相関は残るので、「保有中の途中の情報で決済する規則」（barrier 決済）の帰無にも使える。entry の前の区間と保有の区間の境の、1 本の bar の自己相関（VR < 1 の源）は壊れる。
- **案 C の限界**（独立レビュー Role 1 の指摘）:
  - **複数の entry 時刻の候補の同時の帰無にならない。** 区間の境が規則ごとの entry の時刻に依存するので、09:00 の規則の保有の区間と、09:30 の規則の entry の前の区間が重なる。entry 時刻が違う候補をまとめた max-T（FWER）には、1 つの変換で同時の帰無を作れない。
    - 対策案: 全ての候補の entry と exit の時刻で 1 日を区間に分け、**区間ごとに独立な ±1** を掛ける。
    - そうしない場合は、C を「entry 時刻が 1 つの候補の集合だけ」に限る。
  - **同じ日の entry の前の情報だけを使う規則では、C は日ごとの損益の符号の反転と同じになる。** 保有中の return の条件付きの分布が対称であることを仮定しており、drift と歪度を仮定で消す。
  - **前日以前の情報を使う規則**では、区間の符号の付け方が一貫しない。
- これが帰無仮説そのもの（entry の前と後の独立）に当たることを、事前登録で明記する必要がある。
- 実装と較正は、Cycle 2 が承認された場合に、合成 data で FWER を検証してから行う。今回は設計の比較だけで、code・実 data・max-T の本実行は無い。
