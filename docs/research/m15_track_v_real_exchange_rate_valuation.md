## 0. 保護 span の除外と、データの正直さ

### 0.1 除外は「request の性質」である

裁定 §25 は、保護 span を含む full dataset を download してから local filter する方法を禁じている。
本 track は **request 側で除外**した:

- FX: ECB euro reference rates、`endPeriod=2016-06-01`（fresh pool 開始 `2016-06-02` の前日）。
- CPI: BIS long consumer prices、`endPeriod=2016-05`。
- `fx_url()` / `cpi_url()` は bound を**parse して比較**し、`YYYY-MM-DD`（月次は `YYYY-MM`）の厳密形式以外を拒否する。
  文字列比較では不十分である: `"2016-06"` や `"2016"` は `"2016-06-02"` より辞書順で小さいが、
  SDMX はそれぞれ 6 月末・年末と解釈するので**保護 span の内側**になる。
  また `__ge__` を上書きした `str` subclass は任意の順序比較を通過する
  （本 repo は同じ bypass を過去に 3 route で塞いでおり、初稿はそれを再導入していた — §7 B-1/B-2）。
- 取得後、各系列の**最大**観測日を保護開始日と照合し、届いていれば `ProtectedDataError` で**ファイルを残さず拒否**する。
  書き込みは `try/except/else` の `else` にあり、拒否経路から到達できない。
- この機構は **non-FX dataset のみ**（ECB yield curve、BIS CPI）で事前検証した。FX 観測は検証に 1 つも使っていない。

実際の取得結果: FX 7 系列 × 4,459 行（`1999-01-04 … 2016-06-01`）、CPI 8 系列 × 269 行（`1994-01 … 2016-05`）。
到達不能な source は 0。fresh pool・historical OOS・dead window・forward epoch は読んでいない。

**開示**: BIS API の形を確認する過程で、pre-registration より**前**に 2005–2006 年の日次 JPY/USD ファイルを 1 度取得し、
即座に削除した（header と title のみ表示、観測値は読まず・分析せず・保持せず）。span はどの保護窓の外だが、
順序が逆であったことは事実なので `sources.py` に記録してある。

### 0.2 四半期 CPI の look-ahead — 凍結文が source の性質を誤って記述していた

凍結文は「AU と NZ は四半期公表で、四半期値を同じ lag で carry forward する」と書いている。**BIS はそうしていない。**
四半期の 1 つの値を**その四半期の 3 か月すべてに刻印**する（実測: AUD・NZD とも 90 四半期すべてで月次の相異値が 1 個）。
すると stamped month から lag を数える規則は、公表前の読みに届く:

> 2010-12-31 の決定は label `2010-10` を使うが、その値は **Q4-2010 の豪 CPI** であり、ABS の公表は **2011-01-26**。

該当するのは四半期末の決定月、すなわち建玉のある 151 か月のうち **51 か月（33.8%）**、8 通貨中 2 通貨。

**これは leakage であって設計選択ではない。** lag は「読みが属する四半期の末月」から数えるよう修正した
（凍結した lag 定数を、正しい label に当てたもの）。leakage の除去は救済になりえない —
とくに今回は **leak が失敗した book を良く見せていた**ので、除去すると全指標が下がる:

| book | 凍結文どおり（leak あり） | leak 除去（本文の数値） |
| --- | --- | --- |
| A 実質 valuation | gross +0.192 / net +0.169 | **+0.156 / +0.133** |
| B 名目 control | +0.030 / +0.011 | +0.030 / +0.011（四半期 CPI を使わないので不変） |
| **C 残差（主検定）** | +0.179 / **+0.165** | **+0.140 / +0.127** |

以降の数値はすべて **leak 除去後**。凍結文どおりの版は record の
`as_the_frozen_text_described_the_source` に残してある。

## 1. 問いと、除外すべき対抗仮説

問い: **実質で自国史より割安な通貨は、その後の数か月で超過リターンを生むか。**

対抗仮説は market factor ではなく、もっと単純なものである — **名目の平均回帰**。
名目水準が長期平均から離れただけなら、それは価格統計であって物価水準を必要としない。
valuation の主張は「戻る先の均衡が相対物価とともに動く」ことなので、
**control book は名目乖離そのもの**で、**主検定は control を除去したあとに残るもの**（book C）である。

| 記号 | 定義 |
| --- | --- |
| `n_c` | 通貨 c 1 単位のユーロ建て価値の log（ECB は c/EUR 建てなので log rate の符号反転）、断面で demean |
| `pi_c` | `log CPI_c`（lag 済み）、断面で demean |
| `q_c` | `n_c + pi_c` — 名目が据え置きのまま物価が上がった通貨は実質で割高 |
| `a_c` | `q_c` の expanding mean（観測済みの月のみ、最低 **60 か月**） |
| `d_c` | `q_c − a_c`（正 = 割高） |
| signal | `−d_c` の断面 z-score |

**基準年は打ち消える。** CPI 指数の基準年は国ごとに違うので `log CPI_c` の水準は任意だが、
anchor は各通貨自身の expanding mean であり `d_c = q_c − a_c` は通貨ごとの定数を消す。
残るのは「その通貨自身の歴史からの相対物価の変化」で、それが仮説の対象そのものである。

## 2. 実行設定（すべて凍結済み）

- universe: AUD CAD CHF EUR GBP JPY NZD USD の 8 通貨。routing 可能な pair は **20 本すべて**（universe-closed）。
  identity check: 4,458 日すべてで残差 3.5e-18、欠損 pair 日 0。
- span: return panel `1999-01-05 … 2016-06-01`（4,458 日）、決定月 210。warm-up により**最初の建玉は 2003-12-31**、
  建玉のある決定月は 151、実質 **12.62 年**。
- CPI lag: 月 M の指数は **M+2 の月末**から（四半期公表国は §0.2 のとおり四半期末から）。
- cadence: **毎月末に決定、band 0.10 で月次 rebalance**。執行 layer は Track 1 の universe-closed 版、
  weight cap 0.25、vol target 10%、leverage 上限なし。
- cost: 荷重規約 1.703 bp/片道、**2 倍と 3 倍**でも stress（1999 年まで遡るので規約より spread は広かったはず）。
- 主 horizon: **3 か月 1 本**。robustness anchor は expanding median 1 本のみ、事前宣言済み。

### 3.1 cost は結論を決めなかった — ただし理由は「signal が遅い」だけではない

**この programme で初めて、cost が結論を壊さない book が出た。**

- turnover は **1.25 回転/年**（事前上限 12、T-R2 の D は 59.8、fast は 98.8）。
- 年間 cost **0.14%**（T-R2 の D は 8.17%）。**break-even cost 倍率 10.7**。cost 2 倍で net +0.114、3 倍で +0.101。

ただし **turnover の内訳は「月次 signal」ではない**。band 0.10 は月次決定の **121/150 を止めており**、
売買の大半は vol targeter の leverage 追随である:

| 由来 | turnover（回転/年） | 比率 |
| --- | --- | --- |
| signal（月末の決定） | 0.284 | **22.8%** |
| vol targeter の再 lever | 0.963 | 77.2% |

初稿は「vol targeter が足す売買は年 3 日程度」と書いていた。**逆である**（§7 F4）。
執行 layer には約 1.0 回転/年の**床**があり、signal をどれだけ遅くしてもそこから下がらない。
「1.25 対 59.8」は事実だが、「source が遅いから」で説明できるのはそのうち 2 割強である。

### 3.2 それでも stop である理由

net Sharpe **+0.127** は marginal 帯（0.25）に届かない。加えて 12 条件のうち **6 つ**が落ちる。

| 条件 | 結果 |
| --- | --- |
| A の gross Sharpe > 0 | **満たす**（+0.156） |
| C の gross と net がともに正 | **満たす**（+0.140 / +0.127） |
| C が B に対して正の net 増分 | **満たす**（+0.127 対 +0.011） |
| **割安 tercile から割高 tercile へ単調に減少** | **満たさない**（§3.3） |
| **block の過半が正** | **満たさない**（2 / 6: −0.46, +0.10, −0.03, +1.18, −0.32, +0.28） |
| **1 通貨が gross の半分を超えない** | **満たさない**（CHF が gross の **153.9%**。§3.4） |
| **8 通貨のどれを落としても符号が残る** | **満たさない**（**4 通り負**: AUD −0.07、NZD −0.12、USD −0.18、CHF −0.27） |
| **最良 12 か月を除いても符号が残る** | **満たさない**（除くと −0.072） |
| turnover ≤ 12 | **満たす**（1.25） |
| cost 2 倍・3 倍でも net > 0 | **満たす**（+0.114 / +0.101） |
| robustness anchor（expanding median）で符号不変 | **満たす**（+0.141） |
| **年 5% が vol 15% 以下 かつ gap stress の内側で到達可能** | **満たさない**（必要 vol 39.4%、そこで loss-cut） |

→ **stop**。net が帯に届かない時点で、条件が全部通っていても stop である。

### 3.3 いちばん重要な所見 — 事前登録した経済的順序は、主検定には現れない

事前に「割安 tercile ほど先の超過リターンが高い」という**単調性**を条件に入れていた。3 か月先、147 決定:

| book | 割安 | 中位 | 割高 | 単調か | 割安−割高 (NW t) |
| --- | --- | --- | --- | --- | --- |
| A 実質 valuation | +0.337% | −0.187% | −0.226% | ○ | +0.56pp (0.90) |
| B 名目 control | +0.366% | −0.065% | −0.451% | ○ | +0.82pp (1.33) |
| **C 残差（主検定）** | −0.138% | −0.124% | **+0.393%** | **×（逆転）** | −0.53pp (−1.24) |

初稿はここで「読み方はひとつしかない」と書いた。**書きすぎである**（§7 F8）。
tercile spread はどれも 0 と区別できず、B と A の差（+0.25pp）は **NW t = 0.96** で、主張を担えない。

**主張を担うのは、事前登録していながら初稿が計算しなかった指標のほうである** — `incremental IC`:

| 指標 | 値 | NW t |
| --- | --- | --- |
| A の 3 か月 rank IC | −2.40% | −0.44 |
| B の 3 か月 rank IC | +3.17% | +0.61 |
| C の 3 か月 rank IC | −9.39% | **−2.25** |
| **A − B（valuation の control に対する増分 IC）** | **−5.57%** | **−3.34** |

**t = −3.34 は本実験で最大の統計量である。** 実質 valuation signal の 3 か月断面予測力は、
それが上回るはずだった名目乖離より**有意に悪い**。これは事前登録された主問への直接の答えであり、
初稿が使った tercile 比較よりはるかに強く同じ結論を支持する。初稿はこれを計算せず、
自分の最強の否定的結果を過小に報告していた（§7 F7）。

なお A book の tercile 単調性（+0.34% 対 −0.23%）は予測どおりだが、**同じ signal の 3 か月 IC は −2.40% で符号が逆**である。
3 名/3 名/2 名の tercile を 147 観測で見たものに、record 内のより良い統計量が反しているのだから、
A の単調性を根拠に使うことはできない（§7 F9）。

### 3.4 C の正の Sharpe は何でできているか — 5 日と 1 通貨

事前登録は「上位 1/5/10 日の寄与」と「最大 DD」を metric に挙げていた。初稿はどちらも文書に載せていなかった（§7 F5）。

| 量 | C |
| --- | --- |
| 累積 net | +0.1937 |
| 上位 1 日の寄与 | **41.1%** |
| 上位 5 日の寄与 | **124.9%**（除くと net は負） |
| 上位 10 日の寄与 | 207.3% |
| 最大 DD | **−0.394**（累積 net の 2.0 倍） |
| 正の暦年 | 8 / 13 |

最大の 1 日は **2015-01-15、SNB の対ユーロ下限撤廃**。前日に建てた CHF 建玉が当日の CHF 急騰を取っている。
通貨別でも CHF が gross の **153.9%** を占め（他が相殺しているため 100% を超える）、凍結条件を落とす。

**皮肉な点を明記しておく**: §4 の gap stress は 20% の 1 日 gap を「口座を壊すシナリオ」として扱う。
本 book の最大の 1 日は、まさにその種類の事象の**正しい側**にいたことから来ている。
年 5% に必要な vol 39.4% では、同じ日が逆符号なら 1 セッションで資本の大半を失う。

### 3.5 統計的な位置

この span（建玉 12.62 年）が 80% 検出力で分離できるのは net Sharpe **0.789** 以上。
C の +0.127（net t **0.45**）も A の +0.133（t 0.47）も、**ゼロと区別できない**。
したがって stop は「効かないことの証明」ではなく、**「この span では支持されなかった」**である。

## 4. leverage・margin・利益容量

C 自身の単位 gross あたり vol は 0.0324。

- 10% vol target: risk leverage 平均 **3.09**、leverage tail での margin 利用率 **17.5%**、gap stress 後の維持率 **3.69**。
  loss-cut に至らず、**broker 制約は binding しない**。
- **年 5% は届かない**: net Sharpe 0.127 では必要 vol が **39.4%** になり、凍結条件の上限 15% を超え、
  かつその leverage（risk leverage 平均 12.2）は gap stress で loss-cut に至る。

## 5. 開示する不足（結果の読み方に直接効く）

1. **本 book は spot-only であって、完全な currency excess return ではない。**
   凍結した data source は ECB reference rates と BIS consumer prices で、**どちらも金利を持たない**。
   freeze 後に金利 source を足すことはしていない。

   **偏りの向きは、仮定ではなく実測した**（初稿は教科書的な話から逆向きに断定していた — §7 F2）。
   凍結した CPI panel 上で、signal（割安が正）と相対 trailing 12 か月インフレの断面 Spearman:

   | book | 相関 | NW t |
   | --- | --- | --- |
   | A 実質 valuation | −0.069 | −1.24 |
   | **C 残差（主検定）** | **−0.633** | **−16.4** |

   **C は低インフレ通貨を体系的に買っている。** 残差は実質 signal から名目 signal を除いたもので、
   実質的に相対物価水準の符号反転が残るためであり、構造的である。
   インフレが金利に乗るなら、**欠落している carry は負であり、carry の省略は本 book を過大評価している**。
   trailing 実現インフレは金利そのものではないので証明ではないが、
   議論の中で唯一測定可能な環がこの向きを指している以上、「carry を入れれば通ったかもしれない」は支持されない。
2. **CPI は vintage ではなく改訂後の系列である。** 8 か国を 1994 年まで遡る無料の vintage data は存在しない。
   決定の後に到着した改訂は当時知りえないので、この設計はその分だけ楽観側に偏る。
3. **AU と NZ は四半期公表**（§0.2）。lag を四半期末から数えることで leakage は除いたが、
   月次公表国との情報鮮度は同じではない。

**3 つの偏りはすべて楽観方向である。** 結果が negative なので判定は揺らがないが、
§3.1 の「cost が結論を決めなかった」のような**肯定的な読み**には、この 3 つがそのまま効く。

## 6. 判定と、その scope

**`REAL_EXCHANGE_RATE_VALUATION_NOT_SUPPORTED_IN_DEVELOPMENT`。**

意味するもの: **事前登録した実質 valuation の formulation が、1999–2016 の public data で支持されなかった。**
net Sharpe が帯に届かず、12 条件のうち 6 つが落ち、
**事前登録した増分 IC は −5.57%（t −3.34）で、valuation は名目平均回帰より有意に悪い**。

意味しないもの:

- **「実質為替 valuation に内容が無い」**。この span は net Sharpe 0.79 未満を分離できない。
  ただし増分 IC は「この定式化がこの span で control を上回らなかった」ことを**有意に**示している。
- **「低 turnover の source には価値が無い」**。cost が結論を決めなかったのは programme にとって新しい。
  ただし §3.1 のとおり、低 turnover の 8 割弱は執行 layer の床であって source の性質ではない。
- **carry を含めた valuation の否定**。本 book は spot-only である。ただし §5.1 のとおり、
  測定できる範囲では carry は本 book に**不利**に働く。

### 7.1 開示 — mutation 試験が意図しない再取得を起こした

上記の修正を検証するため、`acquire.py` を含む 43 個の mutation を当てて test suite を走らせた。
そのうち「opt-in check を削除する」mutation の下では、opt-in を検証する test 自身が `acquire()` を本当に実行し、
**network に出て 15 系列を再取得し、committed の `acquisition.json` を上書きした**。

- **保護 span は読んでいない。** URL は同一（`endPeriod=2016-06-01` / `2016-05`）で、
  取得された 15 ファイルは normalised CSV の sha256 が**元の取得と 15/15 一致**する。データは同一である。
- 上書きされた `acquisition.json` は git から復元した。現在の record は 2026-09-18T13:21:32Z の
  **本来の取得**を記録しており、freeze commit の 71 秒後という順序の証拠もそのままである。
- 再発防止として (a) opt-in の test は `_fetch` も stub するようにした（試験対象の機構に依存して offline を保てない）、
  (b) `acquire()` は 1 系列も取得できなかった場合に record を**書かずに raise** するようにした
  （空の record は provenance ではなく、実際にあった取得の記録を消してしまう）、
  (c) 両 test で record の書き込み自体を失敗させる。mutation 43 個を再実行し、`acquisition.json` は無傷である。

順序としては間違いだったので、隠さず記録する。

## 8. 事前登録により禁止されること

- anchor・lag・horizon・cadence・符号・universe の変更。
- control や book や通貨の追加（**carry leg の追加もこれに含まれる**）。

- 非線形化・ML 化。
